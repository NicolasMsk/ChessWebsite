Les périodes

Les valeurs principales portent sur 28 jours, arrêtés à J−3 pour réduire les effets des délais de traitement. WoW compare les 7 derniers jours de cette fenêtre aux 7 précédents. MoM compare les deux mois calendaires complets précédant le mois de fin de fenêtre : ils peuvent avoir un nombre de jours différent. Les plages exactes restent affichées.

Search Console

Recherche Web Google, données finales, toutes les pages disponibles. Le CTR est recalculé comme clics ÷ impressions ; la position est pondérée par les impressions. Les totaux du site proviennent d’une requête Google distincte et peuvent différer de la somme des pages. L’API ne garantit pas l’exhaustivité de toutes les lignes.

GA4 : pages d’entrée et pages consultées

Sessions, utilisateurs entrants, sessions engagées, taux d’engagement, durée de session et événements clés sont attribués à la page d’entrée. Les vues et le temps d’engagement mesurent la page consultée. Un événement clé peut se produire plus tard dans une session commencée sur cette page ; ce n’est pas forcément un événement déclenché sur la page elle-même.

Le filtre « Google organic » restreint GA4 à la source/support « google / organic ». Search Console reste inchangé. Les utilisateurs ne doivent pas être additionnés entre pages ; les tuiles du site utilisent les totaux dédupliqués renvoyés par GA4.

Rapprochement et données absentes

Les chemins d’URL servent de clé ; les paramètres et fragments sont retirés et /index.html est rapproché de /. Les anciennes pages redirigées gardent leur propre ligne. Si plusieurs variantes sont regroupées, les utilisateurs de la ligne peuvent inclure des doublons, signalés dans sa fiche. « — » signifie qu’un indicateur n’est pas calculable ou qu’une source est indisponible ; zéro est une absence d’activité dans les lignes renvoyées, pas une preuve de non-indexation.

Confidentialité

Le serveur écoute uniquement sur 127.0.0.1. Le compte de service demande des accès en lecture seule. La clé reste côté serveur. Les rapports sont mis en cache sur votre ordinateur et exclus de Git ; le tableau de bord entier est exclu de la publication GitHub Pages/Jekyll.
